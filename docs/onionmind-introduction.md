# OnionMind 产品介绍

OnionMind（洋葱）是一款帮助你整理信息、回看思考过程的个人认知工具。它希望把一时想不明白的事，像剥洋葱一样，一层层拆开。

你可以记录图文笔记，通过知乎账号登录并同步近期收藏。面对零散观点与资料，OnionMind 会根据可用摘要生成结构化记忆卡片，提炼核心主张、依据、适用条件、不同意见与延伸问题，同时保留原文入口，让结论能够追溯。

当你主动选择材料分析时，它还会生成认知反馈，帮助区分观察与假设，看见证据、不确定性和可能的反面解释。它不会替你下结论，也不进行心理或医疗诊断，而是提供一面可反复核对的“认知镜子”。

你的笔记属于私人空间；照片仅用于存储与展示，不参与 AI 分析。OnionMind 不追求收藏更多信息，而是让已有信息沉淀为可以理解、追溯和重新调用的知识。
